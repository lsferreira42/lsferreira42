## About me

Systems administrator and developer focused on open source, automation and cloud computing — **10+ years** of experience building and operating production infrastructure.

Currently at **Magalu Cloud** as SRE/DevOps Specialist, working on reliability, scalability and performance of cloud-native platforms. I implement SRE practices (SLIs, SLOs, error budgets, incident response, postmortems), manage advanced Kubernetes clusters and drive GitOps delivery with ArgoCD.

I've also worn the software engineer hat, building APIs and internal tooling in Python, Go and Shell Script — which gives me a solid understanding of both sides of the platform.
